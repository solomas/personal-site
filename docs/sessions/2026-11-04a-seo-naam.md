## Decision taken in the session

The prompt asked for the suffix on every title that is not exactly "Tomás van Gorp", and for a homepage title that starts with the name. Read literally, the homepage would have shown the name twice. The layout instead adds the suffix only when the title does not already start with "Tomás van Gorp". Every other page gets the suffix as asked. A content entry whose title starts with the name would also skip it. None does today.
